## The line

> It was on the floor. My job description is literally just the word 'everything.'

The excuse a robot vacuum gives after eating a sock — deadpan, literal, and
entirely its employer's fault. It was only following its job description.

## How it works

`main.ts` (Node 22, stdlib only, deterministic) writes the line above to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Nothing else: no network, no input, no
side effects.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/laugh-lab-out node main.ts
cat /tmp/laugh-lab-out/entry.txt
```
